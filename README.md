# Password Generator

A simple and secure password generator built with HTML, CSS and JavaScript.

Generate customizable passwords with different character types, password length and password strength feedback.

## Features

* Generate passwords from 4 to 64 characters
* Uppercase and lowercase letters
* Numbers and symbols
* Guarantees at least one character from each selected character type
* Cryptographically secure random character generation
* Password strength indicator
* Copy password to clipboard
* Input validation and error handling
* Responsive design

## Technologies

* HTML5, CSS3, JavaScript, Web Crypto API

## How to use

1. Enter the desired password length.
2. Select the character types you want to include.
3. Click **Generate Password**.
4. Click **Copy** to copy the generated password to your clipboard.

The application runs directly in the browser and does not require any installation or dependencies.
